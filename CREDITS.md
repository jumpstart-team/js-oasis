# Photography credits

Nine of the ten new photographs are free under the Unsplash licence, which permits
commercial use with no attribution required on the live site. This file
exists so the provenance is on record, not because the site must display it.

The tenth, on the contact page hero, is the practice's own storefront photo
(`images/web/wide-exterior.webp`). It was already in this repo and
unreferenced by any page. A real photograph of the building a patient is
looking for beats any stock brick wall on a page headed "Visit us", so the
stock candidate was dropped. It is only 1200x675, so it upscales on a
full-bleed hero; ask Laura for a higher-resolution exterior shot when there
is a reason to be on the phone with her.
